# Tale UI 3.0.0 release notes

Status: prepared, not published.

Tale UI 3.0.0 is the coordinated component-equivalence expansion release for
Tokens, CSS, React, Styles, Themes, and Utils. It establishes Node 18+ consumer
support, React 17/18/19 compatibility, exact React Aria dependency ownership,
versioned v3/v2/v1 documentation, and the package/export validation needed for
the expansion components.

`@tale-ui/tooling@0.2.0` is prepared independently with the same 12 maintained
template IDs, content version 2.0.0, React 3 dependencies, and a Node 22 floor.

No package has been published and no release tag has been created by this
preparation work.
