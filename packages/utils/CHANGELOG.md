# Changelog — @tale-ui/utils

All notable changes to the utility library are documented in this file.

## v2.1.0 — 2026-08-03

### Changed

- **Coordinated release**: Aligned `@tale-ui/utils` with the `2.1.0` release of the Tokens,
  CSS, React, React Styles, and Themes packages.
- **API stability**: Preserved the existing utility APIs while refreshing the coordinated release
  metadata.

## v3.0.0 — 2026-07-27

### Fixed

- Corrected the ID fallback documentation and retained deterministic React 17-compatible ID
  generation for components that cannot call `React.useId`.

### Changed

- Prepared the package for the coordinated Tale UI 3 release.

## v2.0.0 — 2026-07-24

### Changed

- Aligned the package with the Tale UI 2.0 release and renamed repository.
