# Changelog — @tale-ui/tokens

### Changed

- **Release continuity**: Advanced `@tale-ui/tokens` to the coordinated immutable version
  `2.2.0` after `2.1.0` was published.
- **Token stability**: Preserved all token identifiers and generated light/dark values from
  `2.1.0`.

## v2.1.0 — 2026-08-03

### Changed

- **Coordinated release**: Aligned `@tale-ui/tokens` with the `2.1.0` release of the CSS,
  Utils, React, React Styles, and Themes packages.
- **Generated contract**: Refreshed release metadata for the coordinated package set; token
  identifiers and generated light/dark values are unchanged.

### Changed

- Prepared the canonical token package for the coordinated Tale UI 3 release.

- Added generated light- and dark-mode native token objects.
