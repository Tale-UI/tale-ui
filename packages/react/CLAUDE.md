# @tale-ui/react

Read the full [README.md](README.md) before using this library. It contains critical setup steps — rem base, style imports, theme overrides, and dark mode — that will produce broken output if skipped.

When maintaining the package, follow
[`docs/authoring-components.md`](../../docs/authoring-components.md), the
[testing guide](../../test/README.md), and the
[documentation governance rules](../../docs/documentation-governance.md).
Public component changes must keep source, CSS, exports, docs, stories,
component audits, golden prompts, A2UI coverage, and generated artifacts in
sync.
